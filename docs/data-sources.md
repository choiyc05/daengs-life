## 1. 공통 기반 ① — 법령 원문 (국가법령정보센터) [확인]

"출처 링크 + 조항 번호를 함께 응답"이 성능 지표이므로, 법령은 반드시 **조문 단위 구조화 데이터**(API)로 수집한다. 웹 스크래핑 불필요.

- 웹 원문: 한글 URL 패턴 `https://www.law.go.kr/법령/동물보호법` [확인]
- Open API: [open.law.go.kr](https://open.law.go.kr/LSO/openApi/guideResult.do)에서 로그인 → OPEN API 신청 → **OC(이메일 ID)** 발급, 무료 [확인]
- 엔드포인트:
  - 목록: `http://www.law.go.kr/DRF/lawSearch.do?OC={OC}&target=law&type=XML&query=동물보호법`
  - 본문: `http://www.law.go.kr/DRF/lawService.do?OC={OC}&target=law&type=XML&ID={법령ID}` — 조문 단위 XML
- `target` 값: `law`(법령) / `ordin`(자치법규=조례) / `admrul`(행정규칙) / `expc`(법령해석례) / `licbyl`(별표·서식)
- 청킹 전략: XML의 조문 구조를 그대로 청크 경계로 사용 → `documents.section`에 `제16조제2항` 형식 저장

수집 대상 법령:

| 법령 | 커버 도메인 | 핵심 내용 |
|---|---|---|
| 동물보호법 / 시행령 / 시행규칙 | 등록·맹견·전반 | 등록 의무, 안전조치(목줄 2m), 맹견 5종(시행규칙), 맹견사육허가제(2024.4.27 시행), 맹견 책임보험, 과태료 |
| 가축전염병 예방법 | 접종 | 광견병(제2종 가축전염병) 예방접종 명령 |
| 수의사법 | 접종·의료 | 진료·처방 관련 |
| 자연공원법 | 이동·산책 | 국립공원 등 반려동물 출입 제한 |
| 자치법규(조례) — target=ordin | 지자체 지원 | "반려동물" 검색 시 전국 지원 조례 전수 |

## 2. 공통 기반 ② — 찾기쉬운 생활법령정보 (법제처) [확인]

**이번 조사 최대 수확.** 법제처가 운영하는 [생활법령정보 "반려동물과 생활하기"](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=1809)에 등록·외출(목줄·입마개)·대중교통 이용·사육 관리가 **법령 근거와 함께 해설**되어 있다.

- 조문 + 해설이 한 문서에 있어 청킹 품질이 좋고, 정적 HTML이라 크롤 난도 최하
- 도메인 전반을 커버하므로 **Phase 1 최우선 수집 대상**
- trust_level: `official` (해설), 인용되는 조문은 `law`

### 3.2 예방접종 — 신뢰등급 구분이 핵심

접종은 성격이 다른 두 층위가 섞여 있어 **meta의 `trust_level`로 구분** 저장한다:

1. **법정 의무 (`law`)**: 광견병 — 가축전염병예방법 근거. 지자체 무료·지원 접종은 조례/공고와 연계
2. **공공기관 안내 (`official`)**: 농림축산검역본부(qia.go.kr) 동물방역 안내 [요확인], 국립축산과학원 반려동물 포털 [확인], animal.go.kr
3. **수의학 가이드라인 (`guideline`)**: 대한수의사회(kvma.or.kr) [요확인], WSAVA 백신 가이드라인(영문, 참고용) — 종합백신(DHPPL)·코로나·켄넬코프 등 스케줄

챗봇 답변 시 "법정 의무"와 "권장 스케줄"을 구분해 말해야 하므로 수집 단계에서 라벨링해 두면 후처리가 쉬움.

### 3.3 목줄·입마개·맹견

- 법령: 동물보호법(안전조치·맹견관리·책임보험) + 시행규칙(맹견의 범위 — 도사견, 아메리칸 핏불테리어, 아메리칸 스태퍼드셔 테리어, 스태퍼드셔 불 테리어, 로트와일러 + 잡종) [확인]
- **맹견사육허가제** (2024.4.27 시행): 시·도지사 허가, 기질평가, 중성화, 책임보험. 일반 견종도 위해 발생 시 기질평가로 맹견 지정 가능 [확인]
- 해설: [농식품부 보도자료](https://www.mafra.go.kr/) 검색("맹견", "기질평가"), [정책브리핑](https://www.korea.kr/news/policyNewsView.do?newsId=148900501) [확인]
- 주의: 조문 번호는 개정으로 변동됨 → 항상 API 최신본 기준으로 재수집

### 3.5 지자체 지원사업 — 3계층 전략

전국 단일 소스가 없는 가장 지저분한 도메인. 세 층으로 나눠 공략:

1. **[구조화 · 1순위] 보조금24 Open API** [확인]: [행정안전부_대한민국 공공서비스(혜택) 정보](https://www.data.go.kr/data/15113968/openapi.do) — 중앙+지자체 **7,500여 개 서비스** 목록·상세를 API로 제공. "반려", "동물등록", "중성화", "내장형" 키워드 필터링. 지원사업 커버리지의 뼈대.
2. **[안정 · 근거] 조례 전수** [확인]: 법령 API `target=ordin&query=반려동물` → 전국 지원 조례. 공고보다 변동이 적어 RAG 기본 코퍼스로 적합
3. **[신선도 · 모니터링] 고시공고 크롤**: [서울시 고시공고 정보 API (열린데이터광장 OA-2482)](https://data.seoul.go.kr/dataList/OA-2482/S/1/datasetView.do) [확인] — 무료 인증키. 타 지자체는 게시판 크롤(후순위, 필요 지역만)

대표 사례(수집 예): [서울시 내장형 동물등록 지원](https://news.seoul.go.kr/env/archives/522690) — 자부담 1만원, 서울시수의사회 협력 [확인]

## 4. 크롤링 공통 전략

**Phase 1 — 키 없이 즉시 (소량·고품질)**: 생활법령정보(§2) → animal.go.kr → 정부24 → 국립축산과학원 → 법령 웹 원문. 이것만으로 6개 도메인 전부 기본 커버 → **RAG 파이프라인 조기 테스트 가능**

**Phase 2 — 키 발급 후 (구조화 확장)**: 법령 API 조문 단위 재수집 → 보조금24 → 조례 전수 → 보험 약관 PDF

**Phase 3 — 지속 운영**: 고시공고 모니터링(신규 지원사업), 법령 개정 체크, 약관 개정 체크

수집 예절/법적 주의:
- robots.txt 준수, 요청 간격 1~2초, UA에 연락처 명시
- 공공저작물은 대부분 공공누리 제1유형(출처표시) — 페이지별 유형 meta에 기록
- 약관·항공사 안내는 사실정보 위주라 내부 RAG 활용은 무리 없으나, 서비스 표출 시 출처 표기 필수 (성능 지표와도 일치)

저장 규칙·meta 스키마·DB 매핑: [`data/README.md`](../data/README.md)
